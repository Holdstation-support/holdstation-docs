# 🔁 Token Migration

## HOLD Token Migration to Berachain

[View embedded content](https://x.com/HoldstationW/status/1887800791194628117)

Holdstation is embarking on an innovative journey by bridging HOLD tokens to **Berachain** using the **LayerZero bridge**. Here's how you can join this migration:

## How to Bridge

1. Visit [**hold.so**](https://hold.so/swap)**.**
2. Find and click the **"Bridge"** option to start the process.
3. Enter the amount of HOLD you wish to transfer and hit **"Confirm"**.
4. Change your wallet network to Berachain to see your BERA tokens appear in your wallet.

That's it! Now you're part of Holdstation's expansion into the Berachain ecosystem.
